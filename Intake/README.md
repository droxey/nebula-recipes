# Intake

Intake is an AI-native, markdown-first capture system that turns messy input into organized markdown.

## One-line pitch

Capture anything, and Intake files it into the right markdown destination for tasks, notes, events, bookmarks, and research.

## Category statement

Intake is an AI-native personal capture and organization tool for turning unstructured input into structured, correctly filed markdown.

## Why this exists

Most capture tools are good at collecting input but weak at organizing it. Most note systems are flexible but depend on manual filing. Intake is the missing layer between raw input and a clean markdown system.

It takes things like:
- random thoughts
- to-dos
- project ideas
- events
- links to save
- topics to research

Then it decides what each item is, adds useful metadata, and routes it into the correct file and section.

## Core positioning

Public framing:
- AI inbox for thoughts, tasks, events, and links
- turns messy thoughts into organized markdown
- markdown-first personal capture and organization

Avoid framing it as:
- a snippet router
- a parser
- a classifier
- an internal utility

## Brand assessment

"Intake" is strong as a product name because it is:
- short
- clear
- easy to remember
- easy to say
- broad enough to grow beyond one workflow

The weakness is ownership. "Intake" is generic, which means exact-match domains and trademark defensibility are likely weaker than with a more distinctive coined name.

Practical conclusion:
- brand strength: high
- launchability: high
- domain exclusivity: medium to low
- trademark distinctiveness: medium to low

Intake is a good name if the priority is clarity, launchability, and product positioning. It is less ideal if the top priority is a highly ownable standalone brand with clean exact-match naming.
