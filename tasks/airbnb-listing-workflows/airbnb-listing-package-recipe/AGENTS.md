# AGENTS.md

These are the repo-level standards for reusable Airbnb listing workflow assets.

## Scope
Apply these rules when editing recipe files, templates, checklists, or supporting docs for Airbnb listing packaging workflows.

## Rules
- Keep the recipe generic and reusable across listings.
- Put listing-specific exceptions in the listing package folder, not in the base recipe.
- Prefer editing existing workflow files in place.
- Keep naming rules aligned with the account-level Airbnb memory standard.
- Document verification steps explicitly so the workflow can be rerun consistently.
- Keep repo contents lightweight; avoid storing generated media packages unless explicitly intended.
