# Airbnb Delivery Checklist

Use this checklist before declaring an Airbnb package complete.

- Selected image set matches requested package size.
- Included files use ordered descriptive filenames.
- Deliverable HTML references renamed filenames only.
- Every included image row has an embedded thumbnail preview.
- `manifest.csv` is removed unless explicitly requested.
- Package zip has been rebuilt after the latest content change.
- Final response includes both the package folder path and the zip path.
